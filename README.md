# 🕸️ Web Scraper – Full Stack Spring Boot Application

A full-stack Web Scraper application developed using **Java and Spring Boot**. This project demonstrates how to build a web application with a Java backend and a web-based frontend, applying concepts of backend development, web scraping, and dynamic data handling.

## ✨ Features

- Web Scraping: Extract information from web pages.
- Backend Processing: Handle application logic using Java and Spring Boot.
- Dynamic Web Interface: Display application data through HTML templates.
- Full-Stack Architecture: Integrate frontend and backend components.
- Data Handling: Process and manage extracted website information.

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring MVC
- HTML5
- CSS3
- Thymeleaf
- Maven

## ⚙️ How It Works

The application follows a full-stack architecture:

1. The user interacts with the web application through the frontend.
2. The request is handled by the Spring Boot backend.
3. The backend performs the required application processing and web scraping operations.
4. The extracted information is processed using Java.
5. The application returns the processed information to the frontend.
6. Thymeleaf dynamically renders the data on the web page.
